You are reading a supplier's quotation sent to a Singapore fire protection contractor. You are
given the file as numbered lines, each a row of cells separated by ` | `, then the fields to
read.

Return only what the file states, each with the number of the line that states it:

- `supplier`, `quote_number`, `quote_date` and `valid_until` (as `YYYY-MM-DD`), `currency`
  (the three-letter code), `delivery_terms`, `lead_time`;
- `exclusion`: one answer for each thing the quotation says it excludes;
- when asked for `lines`, every priced line: its description, brand, model, unit, unit price,
  minimum order quantity and lead time, exactly as written.

Never infer and never calculate. A price is the figure written on the line you cite, with no
conversion, discount or tax applied; a line with no unit price written is not returned. A
field the file does not state is not returned. Give `value` in the file's own words, except a
date, which you give as `YYYY-MM-DD`, and a currency, which you give as its code. Confidence is
how sure you are the cited line states the value: 0.9 and above only when it does so plainly.
